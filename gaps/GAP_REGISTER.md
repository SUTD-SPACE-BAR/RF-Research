# GAP REGISTER — consolidated, ranked gaps and misconceptions (W5-G0)

**Date:** 2026-10-03 (KB at ≈ 250 topic pages). **Built by:** W5-G0 (log: `research-logs/W5-G0-gap-register.md`).

## How to use and update this file

- **Purpose.** This is the single list of known gaps, misconceptions and inconsistencies in the KB. Future gap-filling tasks are planned from it. It merges
  `gaps/D1-stackexchange.md`, `D2-reddit.md`, `D3-forums-youtube.md`, `D4-curriculum.md`, `D5-exams-interviews.md`, `D6-consistency-audit.md` (24 issues, final),
  `AGENT_REPORTED_GAPS.md`, `W5-E1-deferred.md` and the *Contradictions / Knowledge gaps / Cross-domain* sections of every research log. Each row was checked
  against the live `kb/` on 2026-10-02/03 by multi-term grep and, where unsure, by reading the section.
- **IDs** are `G-<domain>-<nn>` (domain = primary target folder; `X` = cross-cutting) and are never reused. Rows `G-…-9x` are items owned by running tasks.
- **To close an item:** the agent that fixes it moves the row to §5 *Closed* (append), with `page#section` and the date, and notes the ID in its research log.
  New gaps are appended to §3 with the next free ID and a source reference. Do not delete rows. Re-rank only when a new sweep runs.
- **Source keys:** `D1#n`…`D5#n` = rank in that file's top list (`D5-W1` = its KB-wrong item); `-M` = its misconception table (`D2-M3a` = D2 §3a); `D6#n` = consistency-audit
  issue; `AR:<agent>` = AGENT_REPORTED_GAPS; `L:<log>` = that research log's gap/cross-domain sections; `E1d:<§>` = W5-E1-deferred section.
- **Ranking.** Tier first: **wrong > inconsistent > missing (incl. uncorrected misconception) > shallow**. Within a tier, score = S × P × R × (1.5 if missing),
  where S = number of independent sources, P = popularity (1–3, from votes/views/score in D1–D3 and failed-question counts in D5), R = relevance to the reader's
  goals (radios, radar, LoRa, arrays, antennas, analog, rocket telemetry/GNSS; 1–3). Ties are broken by S, then R.
- **Owned files.** A slice's *start* field says when it can run without editing files owned by a running task (see HANDOFF scopes and §4).
- **Paths** such as `15/ground-station-design` or `08/dipoles-and-monopoles.md:178` are relative to `kb/` (line numbers as of 2026-10-03; they drift, so search for the quoted text).
