## Contradictions / discrepancies found
- Multiple-aperture shielding: Brewer (2002) gives −20 log n for n holes within ~λ/2 and a coefficient k = 20–40 in k log(λ/2L); other secondary sources attribute a √n (−10 log n) variant to Ott for some geometries — not verified; page uses the Brewer rule and flags it as an estimate.
- Power-law line test: a global-median detector falsely reported "lines" for QPSK x² and MSK x² (the x^M hump); fixed by a local-median detector — noted so future scripts don't repeat it.
- |diff(discriminator)| method for FSK symbol rate failed in simulation (low-frequency hump dominated); discriminator → LPF → square works (35 dB line). Page uses the latter.
