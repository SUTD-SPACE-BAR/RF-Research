## Contradictions / discrepancies found
- C9: RFD900x sensitivity — DS V1.2 table −111 dBm @12 kb/s (1e-5 BER) vs distributor/other versions '> −121 dBm at low data rates'.
- C8 (minor): Meshtastic docs list LongFast as CR4/5 (radio-settings) and CR4/8 (range-tests page).
- C7 (co-SF capture threshold): Semtech SX1276 CCR_LL = −6 dB (wanted must be ≥6 dB above same-SF LoRa interferer for 1 % PER); Croce 2018 (via S21): co-SF SIR threshold 0 dB; Bor 2016: ~1 dB stronger packet captured if timing favourable. Different definitions (guaranteed PER vs threshold vs experiment) — report all; design with 6 dB.
- C5 (important): EBYTE E220-900T30D claims −147/−148 dBm sensitivity at 2.4 kbps, but it uses LLCC68, which supports only SF5–9 @125 kHz, SF5–10 @250, SF5–11 @500 (no SF12, no BW<125). Best LLCC68 sensitivity ≈ SF9/BW125 (≈ −129 dBm per module datasheets; physics −174+51+6−12.5 ≈ −129.5). EBYTE figure is ~18–19 dB optimistic. Same class of error as W1-A5 C1 for E22.
- C6 (model vs spec; formula now CONFIRMED from rendered DS p.23): my no-tracking drift model gives LDRO relaxation 4× (fold to ±2 bins); Semtech says 16× ⇒ chips track frequency when LDRO on. Semtech non-LDRO limit BW/(3·2^SF) = 1/3 bin total drift vs my 1/2-bin decision boundary (Semtech includes noise margin). Use Semtech numbers as design limits; sim as mechanism.
- C4 (nuance): Semtech SNR table uses 2.5 dB/SF step; ideal non-coherent theory gives 2.77–2.82 dB/SF; measured SX1262 sensitivities (−124 → −137 dBm SF7→SF12) give 2.6 dB/SF. Semtech's table is optimistic vs ideal at SF5–8 by up to 1.3 dB (ideal PER-1 % SNR −1.18 dB at SF5 vs table −2.5) — table is rounded rule, not a measured bound. Report both.
- C3 (minor): RP002-1.0.3 lists Singapore AS923-1 as 920–925 MHz; IMDA TS SRD Rev 3 (Apr 2023) amended to 917–925 MHz. RP002 predates the IMDA amendment; IMDA is authoritative.
- C2 (important, regulatory): Marcus's E22-400T33D (2 W = 33 dBm conducted) at 433 MHz is ~23 dB above Singapore SRD limit (10 mW e.r.p.) and E220-900T30D (1 W) exceeds 917–925 MHz LPWAN end-device limit (100 mW e.r.p., ≤1% duty) — and even the 500 mW e.r.p. class. Flag prominently; legal route (amateur licence / IMDA approval) → domain 19.
- C1 (minor): LDRO threshold wording — SX127x DS says "mandated when symbol duration exceeds 16 ms"; SX126x DS says "usually recommended when Ts ≥ 16.38 ms". Same physics (SF11/BW125 = 16.384 ms is the boundary case: LoRaWAN turns LDRO on at SF11/125 and SF12/125). Record both.
