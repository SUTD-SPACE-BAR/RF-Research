## Ambiguous acronyms in this KB

These acronyms (and a few symbols) mean different things on different pages. Each page is correct in its own context, so read the surrounding text before you assume a meaning. The list comes from grepping every use of each acronym on 2026-10-03 (harvest: `research-logs/raw-harvest/glossary/ambiguous.tsv`, plus manual checks of the contexts). Where a convention choice is involved, [[00/canonical-values-and-conventions]] gives the KB's canonical choice.

(3) **antenna factor** (EMC, dB/m): [[00/decibels-and-log-units]], [[02/electromagnetic-units-and-constants]]. **Page-key collisions.** Several `_sources.md` files cite pages by 2–3-letter keys that look like acronyms: NF (near/far field), MAG (magnetic materials), AF (array factor), PS (phase shifters), PL (planar arrays), TP (tapering), SA (sampling), FE (front-end protection), LS (linear systems), SF (special functions), DE (differential equations), PR (probability), NM (numerical methods), BC (beginner concepts), ROC (rockets, in 21). In those tables, read them as page names, not as the glossary meanings.
